# NCode Manager 1.0
Aprire la cartella in VS Code e avviare index.html con Live Server (localhost). Usare sempre lo stesso indirizzo e porta per conservare i dati. Per PWA usare localhost o HTTPS. Chrome/Edge: menu Installa app; iPhone Safari: Condividi > Aggiungi alla schermata Home. Aprire online almeno una volta per cache offline. PDF: Esporta PDF > Salva come PDF nella finestra di stampa.
Dati locali, nessuna autenticazione o sincronizzazione. Backup JSON dalle impostazioni. Non caricare backup o dati clienti su GitHub. Prima di pubblicare proteggere tutti gli indirizzi con autenticazione server-side. Abbonamenti e pagamenti si registrano manualmente. Prezzi zero nel listino indicano servizi su preventivo, da modificare prima di inviare. IVA iniziale 0 da configurare secondo il regime fiscale. Icona NC provvisoria, logo personalizzabile dalle impostazioni.
